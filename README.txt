Website GlasvezelGemeente.nl
Bestanden: index.html (Home), netwerk.html (Netwerk), assets/ (CSS, contactadres als PNG en illustratie SVG), CNAME.
Publicatie: maak een publieke GitHub repository 'glasvezelgemeente', upload de inhoud van deze map inclusief assets, activeer GitHub Pages vanuit branch main en root. Controleer Settings > Pages > Custom domain glasvezelgemeente.nl. Configureer daarna bij de DNS-beheerder uitsluitend de website-gerelateerde A-records @ naar GitHub (zie GitHub Docs); optioneel CNAME www naar jouw-gebruikersnaam.github.io. Laat MX, SPF, DKIM, DMARC, autodiscover en overige e-mailrecords ongemoeid. Schakel Enforce HTTPS in na DNS-controle.
De e-mail is als PNG zichtbaar en niet klikbaar. Dit beperkt eenvoudige scraping maar voorkomt niet alle vormen van uitlezen.
